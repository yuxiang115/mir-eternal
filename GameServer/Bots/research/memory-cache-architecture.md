# 记忆系统与上下文缓存架构(当前状态,2026-10-08)

自包含文档,可直接发给任何 LLM/工程师求评审。系统背景:传奇 MMO 私服(C# 单进程)内的 LLM 玩家 Bot,目标是"像 2003 年网吧里的真实玩家一样生活",当前 4 个 Bot 常驻,LLM=DeepSeek(thinking 模型 + function calling)。

## 1. 两层记忆

**短期记忆 = 发给 LLM 的 messages 数组**(session,重启即失),总预算 128k token,72k 触发压缩。

**长期记忆 = `BotMemory/<角色名>.json`**(跨重启持久):

| 层 | 内容 | 写入者 | 频率 |
|---|---|---|---|
| Milestones 里程碑 | 升级、重要装备、人生大事 | 服务器自动 + LLM | 极低 |
| Episodes 事件流 | 带 importance(1-5)的经历 | 服务器自动(死亡/捡装备)+ LLM + 压缩要点回写 | 中 |
| Reflections 反思 | 定期提炼的个人观点 | 后台 LLM(当前 20min+5条,计划改事件驱动) | 低 |
| People 人物印象 | dict<名字, 印象文本>(计划升级为追加式 beliefs) | LLM remember 工具 | 低 |
| SelfNote 近况 | LLM 自述心事 | LLM | 低 |
| ~~Progress~~ | ~~10分钟快照~~ → 已改为观察尾部实时生成,不落长期记忆 | 服务器 | (高频,移出) |

## 2. messages 布局(前缀缓存优化后)

```
[0] system   = CommonPromptHead(4号字节一致:传奇文化+行为规则)
              + 个人人格(性格/背景/说话风格/作息/目标)     ← 静态
[1] user     = "[你的记忆]" 稳定层:里程碑/反思/旧事件/近况    ← 低频重写
[2..]        = 对话历史,append-only:
                user: 本轮观察(时段/血蓝/位置/新事件/聊天/工具回执/
                      周围玩家+bot同伴动向/意图/背包装备[指纹变化才带]/
                      [新]服务器事实快照(等级/金币/主手/在干嘛)
                      [新]当前视野玩家的人物印象(按需,短小))
                assistant: 思考摘要 + "[动作] 工具调用摘要"
```

规则:
- 历史严格 append-only;被搭话没回话时追加硬指令重试(私聊用 whisper 回);LLM 失败回滚最后一条观察。
- 滑动截断(TrimHistory)退化为兜底(阈值 80 轮);CompressHistoryAsync 是唯一结构化压缩:72k 阈值,旧 60% 交 LLM 结构化提取("摘要+要点"),产物替换为一条 user 消息,要点回写长期记忆。压缩=受控的会话换代。
- 反思:后台 LLM 把近期 Episodes 提炼为 1-3 条第一人称感悟。
- 跨 bot:公共头字节一致 → 互相命中前缀缓存(未设置 user_id)。

## 3. 实测数据

- 缓存命中率稳态 94~96%,每轮 miss 140-260 token(观察增量)。
- 滑动截断触发瞬间 96%→44%(一次性代价),之后回升 —— 已让位压缩。
- 冷启动后第二个 bot 首跳 72%(命中第一个 bot 的公共头)。
