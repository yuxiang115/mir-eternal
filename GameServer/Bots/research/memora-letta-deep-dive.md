## 一、Memora:记忆变更才是硬问题(实验数据)

### 核心发现(带数字)

1. **遗忘惩罚随时间放大**:记忆 agent 的过时记忆依赖度 周期 18.2 → 季度 **29.5**(裸 LLM 反而下降,因为超窗了干脆看不见)——原文:"Retaining access to older memories without effective forgetting **amplifies inconsistency**"(留着旧记忆而不有效遗忘,会放大不一致)
2. **错误解剖(75 例人工分析)**:
   - 推荐错误 **64% = 没忘掉过时偏好**(用户已从传记转向小说,agent 还推传记)
   - 记忆错误 **72% = 检索不全**(要 4 条只取回 2 条)
   - 推理错误 **100% = 检索不全导致无法整合**(预算问题答"差不多够"而不是算出余额)
3. **记忆 agent 赢在记忆、输在推荐**:Remembering 119 vs 裸 LLM 65(显式记忆有大用);但 Recommending **138 vs 144-153(裸 LLM 反超)**——检索增强≠决策增强,取回一堆但整合不动
4. **FAMA 指标**(方法论贡献):`FAMA = MPA − λ(1−FAA)`,λ=Nforget/(Npresence+Nforget)——**用对有效记忆得分,依赖过时记忆扣分**;标准指标(只看"记没记住")系统性高估长期记忆能力
5. **局限一节原话**:没测"social relationships and multi-user coordination"记忆——**正是我们的主战场**(我们领先这个基准一个身位)

### 对我们的直接映射

| Memora 发现 | 我们的设计 | 行动 |
|---|---|---|
| 64% 错误=没忘掉旧认知 | v1.2 已有 superseded 语义 | **A1:检索层硬规则——workspace_search 只返回当前有效版本,superseded 仅显式查历史时可见**(这是那 64% 的解药,必须做在检索里而不是只做在写入里) |
| 检索不全=最大错误源 | 观察注入"少而相关" | A2:检索宁少勿滥但**带完整性提示**(回执注明"还有 3 条相关,要看吗")——partial retrieval 的坑 |
| FAMA 评测法 | 验收只有"记得"维度 | **A3:记忆验收加"正确忘记"六问**(毒玫瑰案:一周后记得交手✓/新败绩更新判断✓/查现状用最新版✓/能溯源当初为何讨厌✓/过期约战不再牵走✓/Hot 区大小稳定✓) |
| 推荐输给裸 LLM | — | 警示:别指望"检索多=决策好";Hot 区少而准比 Warm 全而杂重要 |

## 二、Letta Code:记忆自律的工程指令集(源码级)

### letta_local_memfs.md(记忆文件系统 prompt)

- 记忆块=**可编辑的系统提示段**;历史=不可变 recall;`[[path]]` 引用="记忆的突触";git 提交才生效;**"编辑记忆不会改变当前回合的行为"**
- **写入纪律**(直接可用):写"纠正过的假设/偏好/错误模式";**"更新应跨情境泛化,而不是记录单个事件"**;"可从历史或文件推导的内容不要写";"Keep blocks lean——精简索引与行为规则,优于大块内容"
- 哲学:"模型是引擎,**你就是你的 token**"

### reflection.md(反思子代理,五阶段)

1. 调查:先看现有记忆结构再动手
2. 提取(带过滤器):候选按优先级=错误与纠正>偏好模式>值得留的新事实>**矛盾**>可复用打法;**一次性细节不存/已有信息跳过/提炼可泛化模式而非事件流水**;技能有门槛(一次性任务不配成为 skill)
3. 更新:**"已有文件覆盖此主题就改它,主题真正独立才建新"**;**"新信息与旧记忆矛盾时,改源头的旧条目——不许把新版本并排粘在旧版旁边"**;人格文件"微创手术式编辑,绝不整篇重写"
4. 审查(无密钥/无过期内容/引用完整)
5. 提交;**"过滤后什么都不剩,就不做任何修改、跳过提交"**——明确合法化"这次没什么值得记的"
- 报告必含 **Skipped 段**(考虑过但不持久化的东西+原因)

### 对我们的直接映射

| Letta 指令 | 我们现状 | 行动 |
|---|---|---|
| 反思五阶段+过滤器 | 反思=定时触发+自由发挥,常产出"捡到铁剑"式流水 | **A4:反思 prompt 全面重写为 Letta 式**——优先级过滤器/泛化而非记录/**改旧优先于建新/矛盾改源头不并排/允许零产出**;恰好同时实现我们欠的"反思事件驱动+去重" |
| "可推导的不写" | remember 常记观察里已有的东西 | A5:remember/workspace_edit 的工具描述加"观察里能再看到的不用记;记规律不记流水" |
| 精简索引优于大块内容 | Hot 预算已定(1.5-3K) | A6:Hot 区结构定型为**索引+行为规则**(指向 Warm 的指针+一句话规律),细节一律 Warm/Cold |
| 编辑不改当前回合 | revision 回执 append 进当轮 | A7:写进原则——回执只影响后续思考轮,本轮决策不因此重算(现状即如此,补文档) |

| [[path]] 突触 | 无 | P2 可选(Knowledge 互链),不进近期 |

## 二点五、GPT 终审核验(2026-10-09,补注)

- 64%/72%/100% 均为**各任务 25 例人工样本内比例**,非总体错误率——引用时须带样本口径
- 主结论表述修正:**"记忆的有效性与完整性,比保存更多信息更重要"**(而非"遗忘比记忆重要")
- Letta 三规则的边界:①一次性事件过滤不适用(游戏角色的身份塑造事件必存);②只返有效版本需类型感知+历史溯源;③"可推导不存"前提是历史可检索——我们的对策=服务器事实先可靠记录、主观解释选择性保存、反复经验再整合
- "领先 Memora 一个身位"撤回:覆盖≠实现优劣;G0 验收改用四维游戏原生评测(Recall/Update/Social Continuity/Behavioral Change)
