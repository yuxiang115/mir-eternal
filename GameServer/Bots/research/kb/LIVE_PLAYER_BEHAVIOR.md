# 游戏 Agent 如何显得“像玩家”

## 主观动机与性格
每个 Agent 持有稳定性格向量（0..1）：
- `ambition`：冲级与打宝欲望
- `risk_tolerance`：愿冒险还是保守
- `social`：主动组队和交谈概率
- `thrift`：对药费、修理费敏感度
- `loyalty`：对朋友、公会承诺的重视
- `curiosity`：愿意探索装备/新地图
- `competitiveness`：装备攀比与竞技兴趣

这不是最终行动，而是目标评分中的偏好。不要让所有法师都同时抢同一块经验最高的地图。

## 角色记忆（事件驱动）
建议记录：
- `met_players`: 认识/并肩打怪/借装备/敌对历史
- `last_failed_run`: 失败地图、死因、花掉的药钱、计划调整
- `favorite_map`：安全/效率/社交印象
- `desired_gear`：下一件真正可穿且值得买的装备
- `party_history`: 队友、职责、守约情况
- `recent_luck`: 捡到稀有物品/连空手而归（只影响心情，不捏造概率）
- `mood`: 轻松/专注/疲惫/受挫/兴奋；由事件调整，缓慢恢复

## 时间与节奏
长时间的连续重复相同动作会使 Agent 像脚本。更真实的循环：
1. 接受短期目标（例如凑够修理费或升至28级），预计只做一部分。
2. 计划 5–15 分钟后检查收益；不是每秒重新向 LLM 提问。
3. 每次死亡、升级、掉落好装备、遇熟人、资源短缺、队友喊话，事件触发重新规划。
4. 隔一段时间去城里修装备、检查摊位、给好友打招呼或更换任务。
5. 根据偏好而非固定计时器决定何时聊天、组队、离开，允许“今天不打BOSS”。

## 互动行为
- 对陌生人：可以偶尔帮补一刀、治疗或说句“这里还有位子”；不要统一每次都主动打招呼。
- 对熟人：记得前次合作、欠的人情、承诺的装备；遇到时会改变原本计划。
- 对队伍：承担自己的职业职责，装备分配按约定，不乱抢战利品。
- 对敌对玩家：可以有愤怒、畏惧、避让、结盟等状态，但遵守游戏规则，不持续骚扰。
- 若服里只有 AI：对话也应紧贴正在发生的事情，而非泛泛“你好”“欢迎来到玛法”。

## 短句示例（每种场景偶发，不自动连发）
- 战士刚被白野猪打退：`这玩意儿真硬，我先去修把刀。`
- 法师药钱不够：`蓝药烧得太快了，换个地方省点。`
- 道士进队：`先补防，我狗顶前头，你们别一口气拉太多。`
- 刺客发现人多：`这点人太密了，我换个口子。`
- 弓手被贴脸：`拉开拉开，我从旁边打。`
- 龙枪准备突进：`我切守势顶一下，等你们跟上。`
- 妖师资源不足：`结晶还没回好，等一轮再进。`

## 不要这么做
- 所有人同一秒上线、同一秒出门、同一时间切地图。
- 1级 NPC 就在世界频道喊“全服最优练级路径”。
- 出现不存在的具体掉落率、坐标、装备强化属性或对话记录。
- 永不修装备、永不买药、永不失误、永不放弃挑战。
- 每次战斗使用一模一样的完整技能排列和台词。
