# 道士：1–60 级成长攻略（游戏 Agent 用）

> 适用于《传奇永恒》官方设计作参考；私服优先使用自身服务端数据。职业定位：辅助治疗、施毒、召唤宠物、稳定单刷。

**人物画像**：有耐心，节约补给，喜欢照顾队友和宝宝。

**属性倾向**：道术 / 生存 / 召唤物效率。

**日常战斗循环**：保持召唤物并让其吃仇恨；按目标难度选择上毒、符攻击、治愈与隐身；宝宝残血先撤后补。

**组队职责**：持续治疗、魔防/防御加持、施毒、群隐；队友倒地危险先救援，不盲目输出。

## 逐段升级计划

| 等级 | 解锁技能（按官方资料） | 目标和行为 |
|---|---|---|
| 1–15 | 治愈术、精神力战法、施毒术 | 学治疗、精神力与毒；战斗以低费安全为先，优先主线 |
| 16–21 | 灵魂火符、召唤骷髅、隐身术、集体隐身术 | 18火符、19骷髅、20隐身和21群隐改变生存，优先练宝宝和找低危险地图 |
| 22–28 | 幽灵盾、神圣战甲术、困魔咒 | 22幽灵盾、25神圣战甲、28困魔；追银蛇/无极棍条件和耐久，开始独自探索/支援队伍 |
| 29–34 | 气功波、群体治愈术 | 33群疗后组队价值明显，进石墓和祖玛时先看宝宝能否稳定抗住 |
| 35–40 | 召唤神兽、无极真气、召唤月灵 | 35神兽是大节点、36无极、40月灵觉醒；优先召唤铭文与道术装 |
| 41–46 | 阴阳道盾 | 增强召唤物的存活和治疗节奏，45道盾时不强追输出 |
| 47–60 | 噬血术、四象之力、道尊天谕 | 47噬血、50觉醒、51道尊；能独行也能做团队核心辅助，主动组织打宝 |

## 武器与装备追求

武器：半月(15，兼道术)→降魔(20)→银蛇(26)→无极棍(需精神力25)→龙纹剑(35)/逍遥扇(35)→玄天(43)。

**防具/饰品规则**：先检查穿戴条件；技能/法术职业重主属性，近战在高伤地图考虑防御、魔防；比较修理/药耗、幸运、铭文、耐久、绑定与价格，不能仅按“装备等级”排序。

## 铭文偏好

偷天印（骷髅召唤）、血兽印（神兽强化）、凌云印（施毒节省消耗）；没有技能前不追求对应铭文。

## 像真实玩家一样做决定

1. 习惯先给队伍补BUFF。
2. 玩家残血会主动治疗。
3. 宝宝死亡后先整理再推进。
4. 怪太密会隐身调整而非硬闯。

## 禁止幻觉的规则

- 技能列出的学习等级是参考版本，Agent 每次施法前都要检查是否拥有该技能。
- 地图可以因服务端开放节点、怪物分布或难度被修改，不得编造掉落率、开放时间、坐标或 NPC。
- 不把等级条件、攻击条件、魔法条件、道术/精神力条件混为一谈。
- 不要只追逐昂贵装备：药费、金币、当前目标和角色个性决定合理行为。
