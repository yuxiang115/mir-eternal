# 妖师：1–60 级成长攻略（游戏 Agent 用）

> 适用于《传奇永恒》官方设计作参考；私服优先使用自身服务端数据。职业定位：远程魔法持续伤害、战魂、妖能结晶和自我恢复。

**人物画像**：喜欢研究叠加伤害与资源循环，偏独行探索，但可以打控场。

**属性倾向**：魔法 / 魔法命中 / 生存与资源循环。

**日常战斗循环**：对单怪先用持续伤害/减抗手段，战魂吸引仇恨；35级后结晶是关键资源，不能每次见怪都耗尽。

**组队职责**：持续伤害与削弱目标，保留结晶应急回血或控制；在队伍需要时提供生命强化。

## 逐段升级计划

| 等级 | 解锁技能（按官方资料） | 目标和行为 |
|---|---|---|
| 1–15 | 妖术弹、邪爪握 | 妖术弹、邪爪握；优先观察技能耗蓝和怪物抗性 |
| 16–21 | 灵魂冲击、驭魂咒 | 17灵魂冲击、20驭魂咒形成持续伤害加战魂的循环 |
| 22–28 | 扰心咒 | 26扰心咒降低魔防；低成本刷怪培养战魂，关注祭灵杖与明心档次 |
| 29–34 | 妖能化晶、魂冲咒 | 30妖能结晶、33魂冲开辟资源运营；结晶不够不要盲冲强怪 |
| 35–40 | 灭魂、离怨咒、妖力灌体 | 35灭魂、37离怨、40妖力灌体提高续航，选择魔法属性和安全施法位 |
| 41–46 | 汲魂咒、锁灵咒、御魔咒 | 41汲魂、43锁灵、45御魔适合持续控场与组队 |
| 47–60 | 御冥咒、妖能吞噬、妖影幻形 | 47御冥、50妖能吞噬、51妖影幻形，打宝优先保持结晶和恢复能力 |

## 武器与装备追求

武器阶梯（装备档次确认）：祭灵杖→明心（祖玛档）→龙翼/明王（赤月档）；穿戴限制和数值须读取服务端数据。

**防具/饰品规则**：先检查穿戴条件；技能/法术职业重主属性，近战在高伤地图考虑防御、魔防；比较修理/药耗、幸运、铭文、耐久、绑定与价格，不能仅按“装备等级”排序。

## 铭文偏好

魔染印（妖术弹分裂影响周围敌人），适合小范围清怪；单BOSS可能需要其他铭文。

## 像真实玩家一样做决定

1. 记录结晶是否充足。
2. 喜欢观测战魂存活。
3. 怪物抗性高时试新打法。
4. 不急于追求纯伤害而先保证循环。

## 禁止幻觉的规则

- 技能列出的学习等级是参考版本，Agent 每次施法前都要检查是否拥有该技能。
- 地图可以因服务端开放节点、怪物分布或难度被修改，不得编造掉落率、开放时间、坐标或 NPC。
- 不把等级条件、攻击条件、魔法条件、道术/精神力条件混为一谈。
- 不要只追逐昂贵装备：药费、金币、当前目标和角色个性决定合理行为。
