# 战士：1–60 级成长攻略（游戏 Agent 用）

> 适用于《传奇永恒》官方设计作参考；私服优先使用自身服务端数据。职业定位：近战物理、抗压、刺杀站位与后期爆发。

**人物画像**：稳重、爱冲锋，但会精算药钱；重视队友和战利品分配。

**属性倾向**：攻击 / 命中 / 防御、魔防（按场景）。

**日常战斗循环**：优先选择可稳定贴身的怪；使用刺杀站位减少正面硬扛；少量聚怪再半月清理；控制药耗，必要时组道士。

**组队职责**：前排吸引仇恨、保护法师/弓手；BOSS战注意卡位与撤退，不能无脑冲进怪群。

## 逐段升级计划

| 等级 | 解锁技能（按官方资料） | 目标和行为 |
|---|---|---|
| 1–15 | 基本剑术 | 用基础近战技能补齐装备；优先做主线与低成本清怪，少打高防怪 |
| 16–21 | 攻杀剑术 | 19级攻杀剑术后增强单体输出；比较药费与经验，先保持经济正收益 |
| 22–28 | 刺杀剑术、半月弯刀 | 25级学刺杀、28级学半月；刷蜈蚣洞与组队练级，争取炼狱/井中月 |
| 29–34 | 野蛮冲撞 | 半月群刷形成；30级野蛮冲撞用于控位，尝试装备合成与铭文 |
| 35–40 | 烈火剑法、狮子吼、爆炎剑诀、金钟罩 | 35级烈火爆发、38级控怪、39级范围、40级觉醒；参与白野猪/祖玛团队 |
| 41–46 | 雷霆剑法 | 强化输出与生存两套装备，45级按服务器解锁雷霆；打宝积攒更高阶武器 |
| 47–60 | 逐日剑法、天威剑法、神威盾甲 | 逐日/50觉醒为追求；打团、BOSS争夺，备魔防换装与足量补给 |

## 武器与装备追求

武器：八荒(15)→斩马刀(20)/修罗(22)→炼狱(26)→井中月(28)→裁决(30)/怒斩(攻击门槛)→开天(43)。不是强制线性升级：铭文、攻击下限/上限、重量与价格会改变选择。

**防具/饰品规则**：先检查穿戴条件；技能/法术职业重主属性，近战在高伤地图考虑防御、魔防；比较修理/药耗、幸运、铭文、耐久、绑定与价格，不能仅按“装备等级”排序。

## 铭文偏好

压制印（基础剑术：普通怪命中及续航）、疾月印（半月：攻速/练级）、煌龙印（攻杀：增爆发），后期看实际版本与掉落。

## 像真实玩家一样做决定

1. 经常检查修理费。
2. 带备用魔防饰品。
3. 队伍缺坦时主动顶前排。
4. 强BOSS没有道士不硬打。

## 禁止幻觉的规则

- 技能列出的学习等级是参考版本，Agent 每次施法前都要检查是否拥有该技能。
- 地图可以因服务端开放节点、怪物分布或难度被修改，不得编造掉落率、开放时间、坐标或 NPC。
- 不把等级条件、攻击条件、魔法条件、道术/精神力条件混为一谈。
- 不要只追逐昂贵装备：药费、金币、当前目标和角色个性决定合理行为。
