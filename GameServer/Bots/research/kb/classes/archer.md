# 弓手：1–60 级成长攻略（游戏 Agent 用）

> 适用于《传奇永恒》官方设计作参考；私服优先使用自身服务端数据。职业定位：远程物理、拉扯、点杀和陷阱控速。

**人物画像**：讲究距离感和地形，有耐心，讨厌被怪贴脸。

**属性倾向**：弓术/远程伤害 / 准确 / 机动。

**日常战斗循环**：优先怪距可控、路线宽的地图；边走边打，先标记优先目标，怪靠近时拉扯或陷阱。

**组队职责**：保持侧翼或后排位置，集火精英和法系怪，不挡战士走位。

## 逐段升级计划

| 等级 | 解锁技能（按官方资料） | 目标和行为 |
|---|---|---|
| 1–15 | 基础射击、精准打击 | 主学基础射击与命中，在广阔地形练移动射击 |
| 16–21 | 二连射、战术标记 | 16二连射、21战术标记；对精英与强怪先标记再集火 |
| 22–28 | 三发散射 | 25三发散射提升多目标输出，开始关注双环战弓/沉锋阶梯和箭矢成本 |
| 29–34 | 击飞射击 | 30击飞对低级敌人有用，保持安全距离，参与组队石墓/祖玛 |
| 35–40 | 强袭、连环暗雷、羿神庇佑 | 35强袭、37暗雷控场、40羿神觉醒；形成拉扯与爆发节奏 |
| 41–46 | 穿刺射击、万箭穿心 | 41穿刺、45万箭；群伤避免误拉额外怪 |
| 47–60 | 凝神、夜幕隐踪、守护箭羽 | 47凝神、50夜幕、51守护箭羽；与队伍协同远程点杀与反击 |

## 武器与装备追求

武器阶梯（仅装备名与档次可确认）：双环战弓→沉锋（祖玛档）→猎首/血染（赤月档）。具体穿戴等级、低阶名称及弓术门槛必须读取服务端数据。

**防具/饰品规则**：先检查穿戴条件；技能/法术职业重主属性，近战在高伤地图考虑防御、魔防；比较修理/药耗、幸运、铭文、耐久、绑定与价格，不能仅按“装备等级”排序。

## 铭文偏好

箭雨印（三发散射：影响目标和周围目标），是否最优看普攻/群刷配置。

## 像真实玩家一样做决定

1. 先看退路再拉怪。
2. 战斗中自动检查箭矢。
3. 和队友保持站位。
4. 经常觉得某处刷怪点地形更好。

## 禁止幻觉的规则

- 技能列出的学习等级是参考版本，Agent 每次施法前都要检查是否拥有该技能。
- 地图可以因服务端开放节点、怪物分布或难度被修改，不得编造掉落率、开放时间、坐标或 NPC。
- 不把等级条件、攻击条件、魔法条件、道术/精神力条件混为一谈。
- 不要只追逐昂贵装备：药费、金币、当前目标和角色个性决定合理行为。

## 本职业首饰追求
可作目标的祖玛首饰：狮纹手镯→血狮腕带；狼首戒指→射手指环；狼牙项链→神射项链。
赤月首饰目标：神射项链→箭灵项链；血狮腕带→箭灵手镯；射手指环→箭灵戒指。
