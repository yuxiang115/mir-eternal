# 龙枪：1–60 级成长攻略（游戏 Agent 用）

> 适用于《传奇永恒》官方设计作参考；私服优先使用自身服务端数据。职业定位：近战物理、冲锋、攻守斗气切换。

**人物画像**：喜欢连续作战和团战，比战士更热衷切姿态和位移。

**属性倾向**：攻击 / 防御 / 斗气技能协同。

**日常战斗循环**：连续横扫+突刺，但别突入不可退出的深处；危险时改游龙防御，稳定后切狂龙提高输出。

**组队职责**：阵线缺盾则守势保护队友；清怪点安全再爆发，优先队友增益。

## 逐段升级计划

| 等级 | 解锁技能（按官方资料） | 目标和行为 |
|---|---|---|
| 1–15 | 中平枪术、伏波荡寇 | 基础枪术、伏波荡寇清理近身敌人 |
| 16–21 | 横扫六合 | 17横扫六合形成前方多目标清怪，控制一次拉怪量 |
| 22–28 | 狂飙突刺、钩镰枪法 | 24狂飙突刺位移、28钩镰撕裂；关注蛇牙枪/青虹武器档次 |
| 29–34 | 乾坤斗气、神威镇域 | 30乾坤斗气是攻守转换核心、33团BUFF形成组队定位 |
| 35–40 | 枪出如龙、御龙晶甲、盘龙枪势 | 35枪出如龙、37晶甲、40觉醒；精英战用防御体系延长生存 |
| 41–46 | 凌云枪法、百战军魂 | 41凌云追击、45百战军魂增强目标持续输出 |
| 47–60 | 燃血化元、龙啸千里、召唤龙驹 | 47燃血化元、50觉醒、51龙驹形成高手套路；积极参加公会战与打宝 |

## 武器与装备追求

武器阶梯（装备档次确认）：蛇牙枪→青虹（祖玛档）→虎咆/横江（赤月档）。具体等级门槛、基础属性需私服表。

**防具/饰品规则**：先检查穿戴条件；技能/法术职业重主属性，近战在高伤地图考虑防御、魔防；比较修理/药耗、幸运、铭文、耐久、绑定与价格，不能仅按“装备等级”排序。

## 铭文偏好

守中印（中平枪术：击败目标概率回复体力），适合续航但非必然最强。

## 像真实玩家一样做决定

1. 经常切换攻防状态。
2. 会观察团队是否缺保护。
3. 突刺前检查位置。
4. 更倾向连刷后休息而不是无限冲。

## 禁止幻觉的规则

- 技能列出的学习等级是参考版本，Agent 每次施法前都要检查是否拥有该技能。
- 地图可以因服务端开放节点、怪物分布或难度被修改，不得编造掉落率、开放时间、坐标或 NPC。
- 不把等级条件、攻击条件、魔法条件、道术/精神力条件混为一谈。
- 不要只追逐昂贵装备：药费、金币、当前目标和角色个性决定合理行为。
