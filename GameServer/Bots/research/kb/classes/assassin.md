# 刺客：1–60 级成长攻略（游戏 Agent 用）

> 适用于《传奇永恒》官方设计作参考；私服优先使用自身服务端数据。职业定位：近战物理、单体爆发、潜行与追击。

**人物画像**：爱单挑，喜欢偷袭精英，重视出手时机而不是肉身抗伤。

**属性倾向**：刺术 / 命中 / 机动与生存。

**日常战斗循环**：先挑单怪/落单精英，潜行接近，技能链爆发后切走；密集怪群强度过高则不硬拼。

**组队职责**：优先处理落单后排/高威胁目标；进退要有计划，避免把怪拉回队伍。

## 逐段升级计划

| 等级 | 解锁技能（按官方资料） | 目标和行为 |
|---|---|---|
| 1–15 | 暴击术、精准术 | 初期训练暴击与命中；别将刺客当坦克使用 |
| 16–21 | 霹雳弹 | 18霹雳弹提供规避，低耗单杀与收集金币优先 |
| 22–28 | 潜行术、致残毒药、鬼灵步 | 22潜行、23毒、28鬼灵步是机动爆发节点；争取追魂与赤影 |
| 29–34 | 炎龙波、旋风腿 | 30炎龙波、32旋风腿形成连段，适合单怪与小团 |
| 35–40 | 冷酷、暗影守卫 | 35冷酷保证技能链、40暗影守卫增强站桩存活；铭文改良爆发 |
| 41–46 | 追魂镖、魔刃天旋 | 41追魂镖和45觉醒增强抓人/清怪，需有撤退路线 |
| 47–60 | 火镰狂舞、猎命宣告、献祭 | 47火镰、50猎命、51献祭形成高级爆发；择机支援团队，不做前排扛怪 |

## 武器与装备追求

武器：铁柴刀(1)→双刀(13)→冰月戟(20)→追魂(26)→赤影(28)→龙爪手(需刺术37)/霜影(需刺术40)/黯灭轮(35)→破天(43)。

**防具/饰品规则**：先检查穿戴条件；技能/法术职业重主属性，近战在高伤地图考虑防御、魔防；比较修理/药耗、幸运、铭文、耐久、绑定与价格，不能仅按“装备等级”排序。

## 铭文偏好

闪击印（精准术：普攻概率对目标及附近触发两段伤害），高级洗炼与服务器规则有关。

## 像真实玩家一样做决定

1. 见落单怪优先观察。
2. 低血直接撤而非硬抗。
3. 经常检查毒药库存。
4. 喜欢研究技能连段和出招窗口。

## 禁止幻觉的规则

- 技能列出的学习等级是参考版本，Agent 每次施法前都要检查是否拥有该技能。
- 地图可以因服务端开放节点、怪物分布或难度被修改，不得编造掉落率、开放时间、坐标或 NPC。
- 不把等级条件、攻击条件、魔法条件、道术/精神力条件混为一谈。
- 不要只追逐昂贵装备：药费、金币、当前目标和角色个性决定合理行为。
